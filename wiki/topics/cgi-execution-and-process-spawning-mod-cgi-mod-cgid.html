CGI Execution and Process Spawning (mod_cgi / mod_cgid)

概念

CGI Execution and Process Spawning は、Apache HTTP Server が外部の CGI (Common Gateway Interface) スクリプトを実行し、そのプロセスと通信するための仕組みです。これには、子プロセスの生成、環境変数のセットアップ、およびプロセスの標準出力（stdout）と標準エラー出力（stderr）を非同期に監視・回収する I/O ハンドリング機構が含まれます。

なぜ重要か

外部プロセスを生成して動的コンテンツを得る CGI 実行において、プロセスの起動オーバーヘッドの管理と、I/O の効率的な処理はサーバー全体のパフォーマンスに直結します。特に、CGI スクリプトの出力（正常なレスポンスデータ）とエラーログ（stderr）をブロッキングすることなく非同期に多重化して読み取る仕組みは、リソースの枯渇を防ぎ、安定したリクエスト処理を実現するために極めて重要です。

関与するモジュール

  • module:modules/generators

主要エンティティ

  • **symbol:modules/generators/cgi_common.h#cgi_bucket_create**: CGI スクリプトの stdout および stderr パイプを非同期的に監視するための、カスタム CGI 型バケットを生成する関数。
  • **symbol:modules/generators/mod_cgi.c#cgi_handler**: mod_cgi における CGI リクエスト処理のメインハンドラ。
  • **symbol:modules/generators/mod_cgi.c#run_cgi_child**: 実際に CGI の子プロセスを生成し、パイプを接続するヘルパー関数。

エンドツーエンドの流れ

提供されたエンティティ情報に基づく、CGI 実行のおおよその流れは以下の通りです。

1. **ハンドラの起動**: リクエストが CGI スクリプトに対するものである場合、cgi_handler が呼び出されます。 2. **環境変数の準備と子プロセスの生成**: cgi_handler は run_cgi_child を呼び出します。run_cgi_child 内部では、ap_create_environment や ap_os_create_privileged_process を用いて、適切な環境変数とともに CGI 子プロセスを生成します。 3. **パイプの監視設定**: プロセス生成後、cgi_handler（または mod_cgid 側のハンドラ）は cgi_bucket_create を呼び出し、子プロセスの stdout (out) と stderr (err) に接続されたパイプを監視するための apr_bucket を作成します。 4. **非同期 I/O の開始**: cgi_bucket_create 内で apr_pollset が作成され、stdout（識別子 1）と stderr（識別子 2）が登録されます。

*注意: mod_cgid におけるデーモンプロセスを介したプロセス生成の具体的な通信プロトコルや、cgi_bucket_read を介したデータの読み出しループなど、エンドツーエンドの完全な詳細フローは提供されたシンボル情報からは未解明です。*

重要な不変条件

  • **非ブロッキング I/O への強制**: cgi_bucket_create に渡された stdout (out) および stderr (err) パイプの APR タイムアウト設定は、関数内部で強制的に 0（非ブロッキング）に上書きされます。
  • **バケットの生存期間**: 生成される CGI バケットの生存期間は、リクエストレコードのプール（request_rec *r の pool）に依存します。
  • **バケットの初期状態**: バケットは bucket_type_cgi 型として初期化され、その長さは (apr_size_t)(-1) に設定されます。

よくある落とし穴

  • **ファイルディスクリプタの枯渇**: cgi_bucket_create 内部での apr_pollset_create または apr_pollset_add の呼び出しが失敗した場合、エラーログ（APLOGNO(01217)〜01219）が出力され、NULL が返されます。これは主に、システムまたはユーザーのファイルディスクリプタ制限（ulimit -n など）に達した際に発生します。
  • **コンパイルマクロの依存性**: cgi_bucket_create は WANT_CGI_BUCKET マクロが定義されている環境でのみ有効です。このマクロが定義されていないビルド環境では使用できません。
